cara membuat project dan debugging dengan opencv:

- buat CMakeLists.txt dengan isi seperti yang tertera

- compile & generate debug : 
  cmake -G "MinGW Makefiles" -B build

- compile : 
  cmake --build build

- execute : 
  build\NamaFile

- compile & generate release : 
  cmake -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -B build

- static linking (opsional) : 
  cmake -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release `
    -DCMAKE_EXE_LINKER_FLAGS="-static -static-libgcc -static-libstdc++" `
    -B build

- rebuild : 
  Remove-Item -Recurse -Force .\build\

- generate dan konfigurasi build(CMakeLists) termasuk penambahan/penghapusan file cpp: 
  cmake -S . -B build

- contoh input path gambar :
  plat1
